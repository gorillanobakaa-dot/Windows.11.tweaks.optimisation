## How to reproduce this

```
powershell -ExecutionPolicy Bypass -File .\Measure-VisualEffects.ps1 -Repeats 2 -Seconds 25
```

The raw counter readings, including every process on the machine at the time,
are in `measurements\` next to this file. That folder is excluded from version
control because it records the machine name and the full process list.
